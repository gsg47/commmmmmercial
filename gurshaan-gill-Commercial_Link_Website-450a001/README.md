# Commercial Link Contracting

Public website for Commercial Link Contracting Ltd. — commercial and residential drywall, insulation, and interior finishing in Alberta and British Columbia.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Cloudflare Workers (OpenNext)

This app deploys with `@opennextjs/cloudflare`. The OpenNext worker is generated by `opennextjs-cloudflare build` into `.open-next/`.

### Dashboard settings

In **Workers & Pages → commercial-link-website → Settings → Builds**:

| Setting | Value |
| --- | --- |
| **Build command** | `npm run build` |
| **Deploy command** | `npx wrangler deploy` |

`npm run build` runs `opennextjs-cloudflare build`. If the dashboard leaves **Build command** empty, a postinstall wrapper still runs that build when Wrangler calls `opennextjs-cloudflare deploy`.

Do not skip the OpenNext build. `npx wrangler deploy` alone cannot upload this Worker until `.open-next/` exists.

### Commands

```bash
npm run build      # OpenNext Cloudflare build
npm run deploy     # build + deploy
npm run preview    # build + local Workers preview
```
